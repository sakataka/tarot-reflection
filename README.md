# Tarot Reflection

タロットカードの象徴を使って相談内容を整理する、ローカル用の遊び・内省支援Webアプリです。カード抽選、正位置 / 逆位置、スプレッド割り当てはアプリ側で機械的に決め、AIは確定済み結果の解釈だけに使います。

## 起動

依存関係はBunで入れます。

```sh
bun install
```

通常はこちらを使います。先に画面をビルドし、画面表示とAI連携APIを同じ port で起動します。port は LocalWeb が割り当てます。ソースを変更したら再ビルドしてください。

```sh
bun run build -- --base ./
localweb dev tarot-reflection
```

起動後、次を開きます。

http://tarot-reflection-dev.localhost/

カードを卓に置くと、このサーバーから選んだAIのCLIを起動し、読み解きを `/api/interpret/stream` で受け取ります。どちらもセッション履歴は保存しません。

LocalWeb を使わずに起動する場合は `PORT` が必須です。

```sh
bun run build
PORT=<port> bun run server
```

フロントエンドをViteで確認し、読み解きも使う場合は、別ターミナルでAPIサーバーを起動します。空いているAPI用portを決め、両方に同じ値を指定してください。

```sh
# APIサーバー
PORT=<api-port> bun run server
# 別ターミナルでVite（上と同じAPI用port）
LOCALWEB_API_PORT=<api-port> bun run dev:frontend
```

画面表示だけなら `bun run dev:frontend` で確認できます。`LOCALWEB_API_PORT` がなければ、APIへのプロキシは設定されません。

## 占い師の言葉を紡ぐAI

ヘッダーの「設定」で Claude（Opus 5.5）と Codex（GPT-6.1 Sol）を切り替えられます。選んだAIはブラウザに保存され、問い返し・語り・聞き返しのすべてに使います。初期値は Claude です。

- Claude: `claude -p --safe-mode --model claude-opus-5-5` を道具なし（`--tools ""`）・履歴なしで呼び、語りを一文字ずつストリーミングで受け取ります。最初の文字が届いたところから語りが始まるので、待ち時間が短くなります。CLI は、Claude デスクトップアプリに同梱された最新版を優先して使います。`~/Library/Application Support/Claude/claude-code/<version>/claude.app/` と `<version>/<build-id>/claude.app/` の両方を探し、見つからなければ PATH などの通常の配置を探します。`TAROT_CLAUDE_BIN` で CLI、`TAROT_CLAUDE_MODEL` でモデルを変えられます。
- Codex: `codex exec --ephemeral --json` を、モデル `gpt-6.1-sol`・推論強度 `medium` で呼びます。完成した本文がまとめて届きます。
- フロントエンドにAPIキーは置きません。どちらもCLIへのログイン（Claude のサブスクリプション、ChatGPT）を使い、`ANTHROPIC_API_KEY`・`OPENAI_API_KEY` は子プロセスに渡しません。
- 読み解きの取得に失敗した場合は、画面から再試行できます。

## 占い師ヴェスペラ

卓の向かいに座る占い師は「ヴェスペラ」（宵の明星の名を持つ、四十代半ばの女性）。自信と威厳があり、神秘的で少し妖艶な話し方をします。人物設定は `src/utils/persona.ts` にまとめてあり、名前もここで変えられます。

- 問いを書いて「ヴェスペラに打ち明ける」を押すと、耳を傾けるヴェスペラの姿が現れ、カードに触れる前に一つだけ問い返します（推論強度 low で数秒〜十秒ほど）。答えは読み解きに使われます。答えずに進むこともできます。
- 語りは、本物の占い師のテンポに寄せています。カードを一枚ずつ手早く返しながら「過去に出たのは、塔の逆さ。」のように短く告げ（一枚一段落）、並びが見えたところで「では、どういうことか」と総括で腰を据えて読み解きます。比喩を使ったら、それが現実のどこを指すかを平らな言葉で言い直させ、カウンセラー（気持ちの問い返し）やコーチ（手順の提示）の口調にはしません。
- 語りの最後は、合図 `[[message]]` のあとの「今夜の答え」（一、二文）で締めます。「今夜の答え」は枠に入れて示します。
- 読み終えたあと、2回まで聞き返せます。新しいカードは引かず、卓のカードを見直して答えます。やりとりは記録にも残ります。保存に失敗した場合は答えを画面に残し、AIに再質問せず保存だけをやり直せます。

## 卓の読み・記録

- 並んだカードから、隣り合う札の元素の関係（エレメンタル・ディグニティ）、大アルカナの比率、スートの偏りと欠け、数字の重なり、人物札、正逆の偏り、数の総和が指す大アルカナ（クインテッセンス）をアプリ側で数え、占い師への依頼に添えます（`src/utils/tableReading.ts`）。
- 混ぜる手を止めたとき、ときどき（20%）一枚が表向きにこぼれ、「こぼれたカード」として脇に置かれます。引き終えた山の一番下は「山の底」として、最後に占い師がめくります。
- 占った日時の月齢・月相と時刻の帯を導入画面と語りに添えます（`src/utils/moment.ts`）。
- 語りを最後まで受け取ったリーディングは、サーバーのあるMacの `~/Library/Application Support/tarot-reflection/readings.json` に保存します（`TAROT_DATA_DIR` で変更可）。ヘッダーの「記録」から読み返し・削除できます。直近45日の最大3件は、占い師が「前にいらしたとき」として触れられるよう依頼に添えます。
- 同じ問いは同じ夜（朝4時まで）に二度占えません。空白・句読点・全角半角の違いは無視して比べます。

## 検証

```sh
bun test
bun run build
```

LocalWebの配信用には `bun run build -- --base ./` を使います。登録済みの配信はこのrepoの `dist` を直接読むため、アプリだけの変更は再ビルド後に通常URLと `/apps/tarot-reflection/` で確認してください。台帳や共通配信設定の変更はLocalWeb側の作業です。

## UIと画像

導入は、月明かりの庭の絵を画面幅いっぱいに置いた WebGL の風景です（`src/components/MoonlitScene.tsx`）。絵の中の月は占う夜の月齢から計算した月相で欠け（明暗の境と地球照をシェーダーで描く）、湖と池の水面が揺れ、空の星が瞬き、ポインタに合わせて手前ほど大きく動いて奥行きを出します。WebGL が使えない環境では同じ絵をそのまま置き、動きを控える設定では動かさずに月相だけを描きます。開いたタブで最初の一度だけ、暗がりに今夜の月を描いてから幕を上げる入口（`Prelude`、触れるかキーで飛ばせる）があり、見出しは一文字ずつ浮かび上がります。画面全体には、ポインタを追う蝋燭の灯りとゆっくり昇る金の塵を重ねています（`AmbientLight`、触れる画面では灯りが漂う）。段が変わるときは View Transitions で前の景色が溶けて次が浮かびます。表に返ったカードは光の輪と粒を散らし、ポインタに合わせて傾いて箔に灯りが走ります（`TiltCard`）。「今夜の答え」は、占った夜の月を上に据えた封書の枠で示します。月の形は `MoonGlyph` で同じ月齢から描き、導入・記録・結果の見出しで共通に使います。欧文の書体は Cormorant Garamond を同梱しています。

夜の占い部屋を思わせる藍黒と古金のUIに、月明かり・藍色・金色をそろえたカード画像を合わせています。カードは自分で「ここで止める」（山に触れても止まります）までリフルシャッフルを続けます（山を左右に割り、内側の角を持ち上げて不規則に交互に落とし、反らせて落とすブリッジのあと揃える。効果音も同じ順に鳴ります）。止めると山を揃え、上から取った山を手で持ち上げて弧を描いて左・右へ運び、三つに切り分けます。指を乗せた山は少し浮きます。選んだ山は手に持ったまま、残りの山を中央へ重ねたあと、最後に上へ載ります。そのあと、山を持った手が卓の弧をなぞり、通ったところに一枚ずつカードを置いていきます（段ごとに向きを折り返すリボン・スプレッド）。引いたカードは扇から抜けて持ち上がり、卓の下の置き場（過去・現在・未来など、7枚は蹄鉄形）へ運ばれます。デスクトップでは卓を画面幅近くまで広げ、カードを大きく扱います。その間、卓の脇からヴェスペラが手順を促します。

結果画面では、上に卓を小さく見渡す帯（スクロールしても留まり、いま語っているカードが光る）を置き、語りの中で一枚ずつカードを大きく表に返します（語りの中の `[[card:N]]` の合図でめくり、話す速さで文字を表示します）。言葉を待つ間は、ヴェスペラの手が伏せたカードの上を位置ごとに順に渡っていく様子を、上の帯のカードを順に光らせて示します。「カードを返していく」を押すと、二枚目以降は一呼吸ずつ置いて続けてめくられ、すべて表になったところで「では、どういうことか」「今夜の答えを聞く」を押して先へ進みます。語りの筆先が画面の下に隠れると自動で送ります。問い返しと聞き返しも、届いた言葉から順に表示します。ヘッダーの「案内」に、占いの流れ・並べ方・こぼれたカードと山の底の意味をまとめています。効果音は Web Audio で合成しています。

ヘッダーの「設定」には、占いの世界の外にある選択をまとめています。いずれもブラウザに保存されます。

- ヴェスペラの言葉を紡ぐAI: Claude（Opus 5.5）/ Codex（GPT-6.1 Sol）
- 語りの見せ方: 一枚ずつ、間を置いて（初期値）/ すぐに全部（届いた言葉をそのまま表示し、合図を待たずにめくる）
- 効果音: 鳴らす（初期値）/ 鳴らさない

ヘッダーの右には卓の外の部屋（記録・図鑑・案内・設定）を置き、開いている部屋だけに金の下線を引きます。どの部屋にも上に「占いに戻る」（占いの途中なら「卓に戻る」）があります。カードを引き始めると進行の横に「最初から」が出て、途中の卓を崩さないよう二度押しで確かめます。設定・案内・記録・図鑑を開いても、問い返しへの入力とカード選びの途中経過は残ります。語りの見せ方を変えると、現在の語りにも反映されます。

画面ごとの作法:

- 問いを置く: 並べ方は三つを横に並べ、選んだものの説明だけを下に出します。打ち明けたあとは入力欄と並べ方を畳み、書いた問いを引用の形で残して、ヴェスペラとのやりとりに目を向けます。
- カードを引く: 卓の上にいつも問いを一行で示します。卓（扇と置き場）は画面の高さに収まる大きさで配り、広げ始めると卓・置き場・下の操作帯が一度に見える位置まで送ります。こぼれたカードの知らせは見出しの行に置きます。
- 言葉を受け取る: 語りの区切りへ送るときは、上に留まる帯の高さを測って、その下にカードが来るようにします。読み終えると「記録に残しました」と示し、最後に「別の問いを置く」「これまでの記録を見る」を置きます。
- 図鑑: スマホでは詳細を下から引き出すシートで見せます（閉じる・背景・Escで閉じ、元のカードへフォーカスを戻す）。スート共通の絵のカードは、一覧にも番号を添えます。

問いは1000字、問い返しへの答えと聞き返しは600字まで書けます（音声入力で長くなっても収まるように）。入力欄は書いた分だけ伸び、結果画面では長い問いを4行で畳んで「問いを全部読む」で開けます。大アルカナ22点、小アルカナのコートカード16点、小アルカナのスート別画像4点、裏面、導入の風景、ヴェスペラの肖像2点の全46点を `public/cards/` に保存しています。コートカード以外の小アルカナ40枚はスートの画像にランクを重ねて区別します。

制作方針と再制作用のプロンプトは [画像の制作方針](docs/image-direction.md) を参照してください。

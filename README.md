# Tarot Reflection

タロットカードの象徴を使って相談内容を整理する、ローカル用の遊び・内省支援Webアプリです。カード抽選、正位置 / 逆位置、スプレッド割り当てはアプリ側で機械的に決め、AIは確定済み結果の解釈だけに使います。

## 起動

依存関係はBunで入れます。

```sh
bun install
```

通常はこちらを使います。画面表示とCodex連携APIが同じ `4192` 番で動きます。

```sh
bun run dev
```

起動後、次を開きます。

http://127.0.0.1:4192/

カードを卓に置くと、このサーバーから選んだAIのCLIを起動し、読み解きを `/api/interpret/stream` で受け取ります。どちらもセッション履歴は保存しません。

ポートを変える場合:

```sh
PORT=4193 bun run server
```

フロントエンドだけをViteで確認する場合:

```sh
bun run dev:frontend
```

この場合、カードの読み解きを使うには別ターミナルで `bun run server` も起動してください。

## 占い師の言葉を紡ぐAI

ヘッダーの「設定」で Claude（Opus 5.5）と Codex（GPT-6 Sol）を切り替えられます。選んだAIはブラウザに保存され、問い返し・語り・聞き返しのすべてに使います。初期値は Claude です。

- Claude: `claude -p --safe-mode --model claude-opus-5-5` を道具なし（`--tools ""`）・履歴なしで呼び、語りを一文字ずつストリーミングで受け取ります。最初の文字が届いたところから語りが始まるので、待ち時間が短くなります。CLI は、Claude デスクトップアプリに同梱された最新版（`~/Library/Application Support/Claude/claude-code/<version>/`）を優先して使います。Homebrew 版は更新が遅く、新しいモデルを呼べないことがあるためです。`TAROT_CLAUDE_BIN` で CLI、`TAROT_CLAUDE_MODEL` でモデルを変えられます。
- Codex: `codex exec --ephemeral --json` を、モデル `gpt-6-sol`・推論強度 `medium` で呼びます。完成した本文がまとめて届きます。
- フロントエンドにAPIキーは置きません。どちらもCLIへのログイン（Claude のサブスクリプション、ChatGPT）を使い、`ANTHROPIC_API_KEY`・`OPENAI_API_KEY` は子プロセスに渡しません。
- 読み解きの取得に失敗した場合は、画面から再試行できます。

## 占い師ヴェスペラ

卓の向かいに座る占い師は「ヴェスペラ」（宵の明星の名を持つ、四十代半ばの女性）。自信と威厳があり、神秘的で少し妖艶な話し方をします。人物設定は `src/utils/persona.ts` にまとめてあり、名前もここで変えられます。

- 問いを書いて「ヴェスペラに打ち明ける」を押すと、耳を傾けるヴェスペラの姿が現れ、カードに触れる前に一つだけ問い返します（推論強度 low で数秒〜十秒ほど）。答えは読み解きに使われます。答えずに進むこともできます。
- 語りは、本物の占い師のテンポに寄せています。カードを一枚ずつ手早く返しながら「過去に出たのは、塔の逆さ。」のように短く告げ（一枚一段落）、並びが見えたところで「では、どういうことか」と総括で腰を据えて読み解きます。比喩を使ったら、それが現実のどこを指すかを平らな言葉で言い直させ、カウンセラー（気持ちの問い返し）やコーチ（手順の提示）の口調にはしません。
- 語りの最後は、合図 `[[message]]` のあとの「今夜の答え」（一、二文）で締めます。「今夜の答え」は枠に入れて示します。
- 読み終えたあと、2回まで聞き返せます。新しいカードは引かず、卓のカードを見直して答えます。やりとりは記録にも残ります。

## 卓の読み・記録

- 並んだカードから、隣り合う札の元素の関係（エレメンタル・ディグニティ）、大アルカナの比率、スートの偏りと欠け、数字の重なり、人物札、正逆の偏り、数の総和が指す大アルカナ（クインテッセンス）をアプリ側で数え、占い師への依頼に添えます（`src/utils/tableReading.ts`）。
- 混ぜる手を止めたとき、ときどき（20%）一枚が表向きにこぼれ、「こぼれたカード」として脇に置かれます。引き終えた山の一番下は「山の底」として、最後に占い師がめくります。
- 占った日時の月齢・月相と時刻の帯を導入画面と語りに添えます（`src/utils/moment.ts`）。
- 語りを最後まで受け取ったリーディングは、サーバーのあるMacの `~/Library/Application Support/tarot-reflection/readings.json` に保存します（`TAROT_DATA_DIR` で変更可）。ヘッダーの「記録」から読み返し・削除できます。直近45日の最大3件は、占い師が「前にいらしたとき」として触れられるよう依頼に添えます。
- 同じ問いは同じ夜（朝4時まで）に二度占えません。空白・句読点・全角半角の違いは無視して比べます。

## UIと画像

夜の占い部屋を思わせる藍黒と古金のUIに、月明かり・藍色・金色をそろえたカード画像を合わせています。カードは自分で「ここで止める」（山に触れても止まります）までリフルシャッフルを続けます（山を左右に割り、内側の角を持ち上げて不規則に交互に落とし、反らせて落とすブリッジのあと揃える。効果音も同じ順に鳴ります）。止めると山を揃え、上から取った山を手で持ち上げて弧を描いて左・右へ運び、三つに切り分けます。指を乗せた山は少し浮きます。選んだ山は手に持ったまま、残りの山を中央へ重ねたあと、最後に上へ載ります。そのあと、山を持った手が卓の弧をなぞり、通ったところに一枚ずつカードを置いていきます（段ごとに向きを折り返すリボン・スプレッド）。引いたカードは扇から抜けて持ち上がり、卓の下の置き場（過去・現在・未来など、7枚は蹄鉄形）へ運ばれます。デスクトップでは卓を画面幅近くまで広げ、カードを大きく扱います。その間、卓の脇からヴェスペラが手順を促します。

結果画面では、上に卓を小さく見渡す帯（スクロールしても留まり、いま語っているカードが光る）を置き、語りの中で一枚ずつカードを大きく表に返します（語りの中の `[[card:N]]` の合図でめくり、話す速さで文字を表示します）。言葉を待つ間は、ヴェスペラの手が伏せたカードの上を位置ごとに順に渡っていく様子を示します。「カードを返していく」を押すと、二枚目以降は一呼吸ずつ置いて続けてめくられ、すべて表になったところで「では、どういうことか」「今夜の答えを聞く」を押して先へ進みます。語りの筆先が画面の下に隠れると自動で送ります。問い返しと聞き返しも、届いた言葉から順に表示します。ヘッダーの「案内」に、占いの流れ・並べ方・こぼれたカードと山の底の意味をまとめています。効果音は Web Audio で合成しています。

ヘッダーの「設定」には、占いの世界の外にある選択をまとめています。いずれもブラウザに保存されます。

- ヴェスペラの言葉を紡ぐAI: Claude（Opus 5.5）/ Codex（GPT-6 Sol）
- 語りの見せ方: 一枚ずつ、間を置いて（初期値）/ すぐに全部（届いた言葉をそのまま表示し、合図を待たずにめくる）
- 効果音: 鳴らす（初期値）/ 鳴らさない

問いは1000字、問い返しへの答えと聞き返しは600字まで書けます（音声入力で長くなっても収まるように）。入力欄は書いた分だけ伸び、結果画面では長い問いを4行で畳んで「問いを全部読む」で開けます。大アルカナ22点、小アルカナのコートカード16点、小アルカナのスート別画像4点、裏面、導入の風景、ヴェスペラの肖像2点の全46点を `public/cards/` に保存しています。コートカード以外の小アルカナ40枚はスートの画像にランクを重ねて区別します。

制作方針と再制作用のプロンプトは [画像の制作方針](docs/image-direction.md) を参照してください。

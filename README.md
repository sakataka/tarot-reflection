# Tarot Reflection

タロットカードの象徴を使って相談内容を整理する、ローカル用の遊び・内省支援Webアプリです。カード抽選、正位置 / 逆位置、スプレッド割り当てはアプリ側で機械的に決め、AIは確定済み結果の解釈だけに使います。

## 起動

依存関係はBunで入れます。

```sh
bun install
```

通常はこちらを使います。先に画面をビルドし、画面表示とAI連携APIを同じ port で起動します。port は LocalWeb が割り当てます。ソースを変更したら再ビルドしてください。

```sh
bun run build -- --base ./
localweb dev tarot-reflection
```

起動後、次を開きます。

http://tarot-reflection-dev.localhost/

カードを卓に置くと、このサーバーから選んだAIのCLIを起動し、読み解きを `/api/interpret/stream` で受け取ります。どちらのAIもセッション履歴は保存しません。

LocalWeb を使わずに起動する場合は `PORT` が必須です。

```sh
bun run build
PORT=<port> bun run server
```

フロントエンドをViteで確認し、読み解きも使う場合は、別ターミナルでAPIサーバーを起動します。空いているAPI用portを決め、両方に同じ値を指定してください。

```sh
# APIサーバー
PORT=<api-port> bun run server
# 別ターミナルでVite（上と同じAPI用port）
LOCALWEB_API_PORT=<api-port> bun run dev:frontend
```

画面表示だけなら `bun run dev:frontend` で確認できます。`LOCALWEB_API_PORT` がなければ、APIへのプロキシは設定されません。

## 占い師の言葉を紡ぐAI

ヘッダーの「設定」で Claude（Opus 5.5）と Codex（GPT-6.1 Sol）を切り替えられます。選んだAIはブラウザに保存され、問い返し・語り・聞き返しのすべてに使います。初期値は Claude です。

- Claude: `claude -p --safe-mode --model claude-opus-5-5` を道具なし（`--tools ""`）・履歴なしで呼び、語りを一文字ずつストリーミングで受け取ります。最初の文字が届いたところから語りが始まるので、待ち時間が短くなります。CLI は、Claude デスクトップアプリに同梱された最新版を優先して使います。`~/Library/Application Support/Claude/claude-code/<version>/claude.app/` と `<version>/<build-id>/claude.app/` の両方を探し、見つからなければ PATH などの通常の配置を探します。`TAROT_CLAUDE_BIN` で CLI、`TAROT_CLAUDE_MODEL` でモデルを変えられます。
- Codex: `codex exec --ephemeral --json` を、モデル `gpt-6.1-sol`・推論強度 `medium` で呼びます。完成した本文がまとめて届きます。
- フロントエンドにAPIキーは置きません。どちらもCLIへのログイン（Claude のサブスクリプション、ChatGPT）を使い、`ANTHROPIC_API_KEY`・`OPENAI_API_KEY` は子プロセスに渡しません。
- 読み解きの取得に失敗した場合は、画面から再試行できます。

## 占い師ヴェスペラ

卓の向かいに座る占い師は「ヴェスペラ」（宵の明星の名を持つ、四十代半ばの女性）。自信と威厳があり、神秘的で少し妖艶な話し方をします。人物設定は `src/utils/persona.ts` にまとめてあり、名前もここで変えられます。

- 問いを書いて「ヴェスペラに打ち明ける」を押すと、耳を傾けるヴェスペラの姿が現れ、カードに触れる前に一つだけ問い返します（推論強度 low で数秒〜十秒ほど）。答えは読み解きに使われます。答えずに進むこともできます。
- 語りは、本物の占い師のテンポに寄せています。カードを一枚ずつ手早く返しながら「過去に出たのは、塔の逆位置。」のように短く告げ（一枚一段落）、並びが見えたところで「では、どういうことか」と総括で腰を据えて読み解きます。比喩を使ったら、それが現実のどこを指すかを平らな言葉で言い直させ、カウンセラー（気持ちの問い返し）やコーチ（手順の提示）の口調にはしません。
- 語りの最後は、合図 `[[message]]` のあとの「今夜の答え」（一、二文）で締めます。「今夜の答え」は枠に入れて示します。朝（5〜10時）に占えば「今朝の答え」、昼（10〜17時）なら「今日の答え」と、占った時刻で呼び名が変わります。
- 読み終えたあと、2回まで聞き返せます。ヴェスペラが「見えにくいところは、山からもう一枚引いて照らしましょう」と促し、便箋に書いたあと「もう一枚引いて、照らす」か「このまま聞く」を選びます。補足の一枚（クラリファイア）は、読みの曖昧なところを照らすために一枚足す、現代のタロットで広く使われる作法です。引く場合は既出札と重ならない札をサーバーで確定し、通信をやり直しても同じ札を使います。引かない場合は卓のカードを見直して答えます。やりとりと補足札は帳面に残ります。保存に失敗した場合は答えを画面に残し、AIに再質問せず保存だけをやり直せます。

## 卓の読み・帳面

- 並んだカードから、隣り合う札の元素の関係（エレメンタル・ディグニティ）、大アルカナの比率、スートの偏りと欠け、数字の重なり、人物札、正逆の偏り、数の総和が指す大アルカナ（クインテッセンス）をアプリ側で数え、占い師への依頼に添えます（`src/utils/tableReading.ts`）。
- 混ぜる手を止めたとき、ときどき（20%）一枚が表向きにこぼれ、「こぼれたカード」として脇に置かれます。引き終えた山の一番下は「山の底」として、最後に占い師がめくります。
- 占った日時の月齢・月相と時間帯を導入画面と語りに添えます（`src/utils/moment.ts`）。
- 語りを最後まで受け取ったリーディングは、サーバーのあるMacの `~/Library/Application Support/tarot-reflection/readings.json` に保存します（`TAROT_DATA_DIR` で変更可）。ヘッダーの「帳面」から読み返し・削除（頁を破る）できます。帳面は月の巡り（新月から次の新月まで、平均の月齢で数える）ごとにまとめ、巡りごとに三十の小さな月を並べて、相談のあった夜に灯をともします。直近45日の最大3件は、占い師が「前にいらしたとき」として触れられるよう依頼に添えます。
- 同じ問いは同じ夜（朝4時まで）に二度占えません。空白・句読点・全角半角の違いは無視して比べます。

## 部屋の時刻・音・声

- 部屋の時刻（`roomHour`）: 夜（19〜5時）・夕暮れ（17〜19時）・朝（5〜10時）・昼（10〜17時）で、導入の見出し（今夜／今朝／今日のカードに）と窓の景色が変わります。昼はカーテンを引いた部屋（景色の両脇にビロードの幕）、明け方は山の端が白み、夕暮れは染まります。占い師への依頼にも部屋の様子を添えます。
- 部屋の音（`src/utils/ambience.ts`）: 低い部屋鳴り、蝋燭の芯がはぜる音、夜と夕暮れは遠くの虫、朝は遠い鳥を、Web Audio でごく小さく合成し続けます。ブラウザが音を許す最初の操作のあとで流れはじめ、「設定」で止められます。答えを囁いている間は音を下げます。
- 答えの囁き（`server/whisper.ts`）: 最後に、めくった札を一言ずつ振り返る短い語り（合図 `[[recap]]` のあと。画面には出さず声にだけ使う）に続けて、「今夜の答え」を、ヴェスペラの声で囁きます。止める・聴き直すといった操作は置きません。声は Gemini Narration Lab（このMacの音声合成API）でサーバーが作り、`TAROT_DATA_DIR` 側の `whispers/` に保存して使い回します。語りが届き終えた時点で声を裏で先に作っておき、答えの枠が開いたら先に囁き、言い終えてから文字を浮かべます（囁いている間は枠に灯りだけが息づき、聞き返し欄も出しません。25秒待っても声が出なければ文字で示します）。「設定」で「文字だけ」を選ぶか、語りの見せ方が「すぐに全部」なら、従来どおり文字を先に出します。トークンがなければ囁きの表示は出ず、文字だけで占えます。生成に失敗しても自動では作り直しません（有料のため）。

囁きを使うには、Gemini Narration Lab の画面右上「API連携」で、IDを `tarot-reflection` にしてトークンを発行し、このrepoの `.env` に次の2行を入れてサーバーを起動し直します（`.env.example` に雛形があります）。声は `TAROT_VOICE`、読み方の指示は `TAROT_VOICE_STYLE` で変えられます（初期値は日本語の語り手の声 `ja-jp-storyteller-3`。48歳・低め・引き込む力と共感）。

```dotenv
NARRATION_API_URL=http://gemini-narration.localhost/api/v1
NARRATION_API_TOKEN=gn_...
```

## 見送り

読み終えても「別の問い」へは促しません。聞き返しを終えて「卓を閉じる」を押すと、ヴェスペラが時刻に合わせた一言で見送り、答えを封をした書状にして手渡します。「封書を持ち帰る」で、占った夜の月・答え・卓に出たカードを一枚の絵（1080×1350 の PNG、問いそのものは書かない）として保存できます。「礼を言って、席を立つ」で蝋燭が吹き消され、部屋の音も止んで暗くなります。「もう一度、灯りをともす」で入口へ戻ります。

## UIと画像

導入は、月明かりの庭の絵を画面幅いっぱいに置いた WebGL の風景です（`src/components/MoonlitScene.tsx`）。絵の中の月は占う夜の月齢から計算した月相で欠け（明暗の境と地球照をシェーダーで描く）、湖と池の水面が揺れ、空の星が瞬き、ポインタに合わせて手前ほど大きく動いて奥行きを出します。WebGL が使えない環境では同じ絵をそのまま置き、動きを控える設定では動かさずに月相だけを描きます。開いたタブで最初の一度だけ、暗がりに今夜の月を描いてから幕を上げる入口（`Prelude`、触れるかキーで飛ばせる）があり、見出しは一文字ずつ浮かび上がります。画面全体には、ポインタを追う蝋燭の灯りとゆっくり昇る金の塵を重ねています（`AmbientLight`、触れる画面では灯りが漂う）。段が変わるときは View Transitions で前の景色が溶けて次が浮かびます。表に返ったカードは光の輪と粒を散らし、ポインタに合わせて傾いて箔に灯りが走ります（`TiltCard`）。「今夜の答え」は、占った夜の月を上に据えた封書の枠で示します。月の形は `MoonGlyph` で同じ月齢から描き、導入・帳面・結果の見出しで共通に使います。欧文の書体は Cormorant Garamond を同梱しています。

夜の占い部屋を思わせる藍黒と古金のUIに、月明かり・藍色・金色をそろえたカード画像を合わせています。カードは自分で「ここで止める」（山に触れても止まります）までリフルシャッフルを続けます（山を左右に割り、内側の角を持ち上げて不規則に交互に落とし、反らせて落とすブリッジのあと揃える。効果音も同じ順に鳴ります）。止めると山を揃え、上から取った山を手で持ち上げて弧を描いて左・右へ運び、三つに切り分けます。指を乗せた山は少し浮きます。選んだ山は手に持ったまま、残りの山を中央へ重ねたあと、最後に上へ載ります。そのあと、山を持った手が卓の弧をなぞり、通ったところに一枚ずつカードを置いていきます（段ごとに向きを折り返すリボン・スプレッド）。引いたカードは扇から抜けて持ち上がり、卓の下の置き場（過去・現在・未来など、7枚は蹄鉄形）へ運ばれます。デスクトップでは卓を画面幅近くまで広げ、カードを大きく扱います。その間、卓の脇からヴェスペラが手順を促します。

結果画面では、上に卓を小さく見渡す帯（スクロールしても留まり、いま語っているカードが光る）を置き、語りの中で一枚ずつカードを大きく表に返します（語りの中の `[[card:N]]` の合図でめくります）。カードの段落は、札を返して一呼吸おいたところで一度にまとめて示し、前置きと総括は話す速さで文字を置きます。言葉を待つ間は、ヴェスペラの手が伏せたカードの上を位置ごとに順に渡っていく様子を、上の帯のカードを順に光らせて示します。「カードをめくっていく」「二枚目をめくる」のように、一枚ごとに相談者の合図でめくり、すべて表になったところで「では、どういうことか」「今夜の答えを聞く」を押して先へ進みます。札の英名と意味のキーワード（札の裏書き）は、語りの途中には出さず、語り終えてから開けるようにしています。語りの筆先が画面の下に隠れると自動で送ります。問い返しと聞き返しも、届いた言葉から順に表示します。ヘッダーの「作法」に、占いの流れ・並べ方・こぼれたカードと山の底の意味をまとめています。効果音は Web Audio で合成しています。

ヘッダーの「設定」には、占いの世界の外にある選択をまとめています。いずれもブラウザに保存されます。

- ヴェスペラの言葉を紡ぐAI: Claude（Opus 5.5）/ Codex（GPT-6.1 Sol）
- 語りの見せ方: 一枚ずつ、間を置いて（初期値）/ すぐに全部（届いた言葉をそのまま表示し、合図を待たずにめくる）
- 効果音: 鳴らす（初期値）/ 鳴らさない
- 部屋の音: 流す（初期値）/ 流さない
- 答えの囁き: 囁いてもらう（初期値。声の準備があるときだけ）/ 文字だけ

ヘッダーの左は「Moonlit Tarot」、右には部屋の中の物（帳面・札箱・作法）と、少し離して舞台裏の「設定」を置き、開いている部屋だけに金の下線を引きます。どの部屋にも上に「卓へ戻る」があります。占いの進み具合は段の番号や文字ではなく、ヘッダーの小さな蝋燭の長さ（打ち明ける → カードを引く → 言葉を聴く、で短くなる）で示します。蝋燭は画像生成した版画風の絵（`public/cards/candle_1〜3.webp`、黒地を透過）で、炎の位置に灯りを重ねて揺らします。カードを引き始めると蝋燭の横に「卓を片づける」が出て、途中の卓を崩さないよう二度押しで確かめます。設定・作法・帳面・札箱を開いても、問い返しへの入力とカード選びの途中経過は残ります。語りの見せ方を変えると、現在の語りにも反映されます。

画面ごとの作法:

- 問いを置く: 問いは蝋燭の灯りが落ちた便箋（`LetterPaper`）に書きます。見出し・例文・文字数は出さず、上限の9割を超えたときだけ「紙の余白が、あと少しです」と知らせます。問い返しへの答えと聞き返しも同じ便箋です。導入の風景は低く抑え、見出しと月の一行だけを置いて、便箋が最初の画面に入るようにしています。並べ方は1枚・3枚・7枚ホースシュー・10枚ケルト十字から選びます。打ち明けたあとは入力欄と並べ方を畳み、書いた問いを引用の形で残して、ヴェスペラとのやりとりに目を向けます。
- カードを引く: 卓の上にいつも問いを一行で示します。卓（扇と置き場）は画面の高さに収まる大きさで配り、広げ始めると卓・置き場・下の操作帯が一度に見える位置まで送ります。こぼれたカードの知らせは見出しの行に置きます。枚数の表示・山の名札・混ぜ直し・操作の説明は出さず、次に引く位置はヴェスペラの言葉と卓の置き場（過去・現在・未来など）で示します。切り分けた山や広げた札は札ごとにわずかにずれ、引いた札は扇から抜き取ってから弧を描いて置き場に落ち着きます。
- 言葉を受け取る: 語りの区切りへ送るときは、上に留まる帯の高さを測って、その下にカードが来るようにします。読み終えると「帳面に綴じました」と示し、最後に「卓を閉じる」を置きます（見送りへ）。
- 札箱: スマホでは詳細を下から引き出すシートで見せます（閉じる・背景・Escで閉じ、元のカードへフォーカスを戻す）。78枚すべてを個別の画像で表示します。

問いは1000字、問い返しへの答えと聞き返しは600字まで書けます（音声入力で長くなっても収まるように）。入力欄は書いた分だけ伸び、結果画面では長い問いを4行で畳んで「問いを全部読む」で開けます。大アルカナ22枚、小アルカナ56枚はすべて個別の画像を使います。小アルカナのランクとスートは左上・右下に添え、中央の大きな数字は重ねません。`public/cards/` は現役のカード78点・裏面・導入の風景・ヴェスペラの肖像2点・ヘッダーの蝋燭3点と、制作時の参照用に残した旧スート共通画像4点の計89点です。

小アルカナ56枚の正位置・逆位置の意味は、RWS系の各札固有の象徴に沿って定義しています。原典の逐語訳ではなく、この部屋の内省向けの日本語解釈です。ケルト十字はウェイト版の十の位置を用い、別の象徴札を選ばない簡略版です。基準と採用した作法は [タロットの基準](docs/tarot-tradition.md) を参照してください。

数札40枚は2026-10-04にDotsから納品され、表示とAI向けの場面説明へ反映済みです。制作依頼・納品パス・ファイル名・プロンプトは [Dotsへの画像制作依頼](docs/dots-minor-arcana-artwork-brief.md) にまとめています。

制作方針と再制作用のプロンプトは [画像の制作方針](docs/image-direction.md) を参照してください。

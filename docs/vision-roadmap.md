# Moonlit Tarot: Quality Roadmap

このドキュメントは、完成度を継続して引き上げるための優先順位を置く。2026-07-25 の品質向上で、問い・カード選択・結果を3段階の体験に整理し、大アルカナ22枚、スート別の小アルカナ4枚、専用カード裏面を実装した。

## 実装済み

- 大アルカナ22枚を、藍黒・古金・月相・植物線画の同一アートディレクションで制作した。
- 小アルカナはワンド・カップ・ソード・ペンタクルごとに共通絵を制作し、A〜X・PAGE・KNIGHT・QUEEN・KINGをコード上の古典書体で重ねる方式にした。
- 選択前に最も長く見るカード裏面を専用画像にし、スプレッドのプレビューにも共通利用した。
- 画面を「問いを置く」「カードを選ぶ」「言葉を受け取る」の3段階へ整理した。
- 占い師が向かい側からカードを差し出す卓を制作し、78枚を横スクロールなしで一望できる選択画面にした。
- iPhone Air相当の420 × 912 pxを含むレスポンシブ表示、キーボードフォーカス、reduced motionへ対応した。
- 2026-09-23: UI全体を藍黒・古金・明朝体の夜の卓へ刷新した。シャッフル（リフル）→卓へ配って弧状に広げる演出、選択時の浮き上がりと金の光、結果画面での一枚ずつのめくり、蝋燭の待機表示、段落が浮かび上がる占い師の言葉を実装した。
- 効果音（シャッフル、選ぶ、戻す、めくる、言葉が届いた合図）を Web Audio で合成し、ヘッダーからオンオフできるようにした。初期状態はオンで、選択した設定を保存する。
- 読み解きプロンプトを、見出し・箇条書きのない占い師の語りへ変更した。各カードの実際の絵柄（`src/data/cardImagery.ts`）を渡し、絵に触れながら読むようにした。
- 2026-09-24: 占い師の語りをストリーミングで受け取り、話す速さ（句点・段落で間を置く）で表示するようにした。カードは伏せたまま置き、語りの中の合図 `[[card:N]]` で一枚ずつめくってからそのカードを語る。締めは `[[close]]` のあとに全体を見渡して語る。「語りを先まで読む」で待たずに読める。
- シャッフルを自分で止め、三つに分けた山から一つを選んで上に載せるカットの儀式を加えた。
- 2026-09-27: 本物の占い師の作法に寄せた。並び全体の技法（元素の関係、大アルカナの比率、スートの偏りと欠け、数字の重なり、人物札、クインテッセンス）をアプリで数えて語りに渡す。ジャンピングカード（こぼれたカード）と山の底のカードを加えた。月相と時刻を導入と語りに反映し、リーディングを記録して読み返せるようにし、直近の記録を占い師が覚えている形にした。同じ問いを同じ夜に二度占わない作法を入れた。
- 2026-09-27: コートカード16枚を個別の人物画にした（2×2の4枚組で生成して切り出し）。
- 2026-09-27: 占い師を「ヴェスペラ」という一人の人物にした。カードを引く前に一問だけ問い返し、読み終えたあと2回まで聞き返せる。
- 2026-09-27: 問い返しと語りの待ち時間の蝋燭を、ヴェスペラの肖像画（耳を傾ける姿・カードに手をかざす姿）に替えた。シャッフルからカットまでを、揃える→上から三つに切り分ける→選んだ山を持ち上げて最後に上へ載せる、の一続きの手つきにし、各段階でヴェスペラが促す。
- 2026-09-27: 結果画面を、上に留まる卓の帯と、語りの中で一枚ずつ大きくめくるカードに作り直した。区切りごとに相談者の合図で次へ進む。最後に卓全体の総括と「今夜の答え」を置いた。ヘッダーに「案内」を加えた。
- 2026-09-29: 占い師の言葉を紡ぐAIを Claude（Opus 5.5）と Codex から選べるようにした（初期値は Claude）。Claude は語りを一文字ずつストリーミングで受け取るので、最初の文字が届いたところから語りが始まる。語りの組み立てを「一枚ずつ短く告げる → では、どういうことか」のテンポに変え、総括で核心を平らな言葉で言い切るようにした。二枚目以降のカードは合図を待たずに続けてめくる。待ち時間は、占い師の手が伏せたカードの上を順に渡る表示にした。デスクトップでは卓を広げてカードを大きくし、配る動きを「山を持った手が弧をなぞって置いていく」形に、引いたカードは卓の下の置き場へ運ぶ形にした。
- 2026-09-29: AI・語りの見せ方（一枚ずつ／すぐに全部）・効果音をヘッダーの「設定」にまとめ、卓の上から舞台裏の選択を外した。シャッフルを、左右に割って交互に落とし、ブリッジして揃える本物のリフルの手つきにした（音も同じ順）。カットと山を重ねる動きは、手で持ち上げて弧を描いて運ぶ形にした。問いの上限を1000字に広げた。
- 2026-09-30: 画面全体の使い勝手を見直した。ヘッダーを「記録・図鑑・案内・設定」の固定の名前にして開いている部屋を示し、スマホでは2段に収めた。「最初から」は二度押しで確かめる。導入は短くし、打ち明けたあとは問いを引用で残す。卓は問いを常に示し、画面の高さに収まる大きさで配って置き場まで一度に見せ、扇の両端の見切れを直した。語りは帯の下へ正しく送り、待ち時間の表示を一画面に収め、読み終えたあとに次の一歩を置いた。図鑑はスマホで下からのシートにし、数札に番号を添えた。

- 2026-10-02: 導入を、絵の月が今夜の月相で欠ける WebGL の風景に作り替えた（水面の揺れ、星の瞬き、ポインタの奥行き）。入口の幕、蝋燭の灯りと金の塵、段の切り替えの View Transitions、カードを返す瞬間の光と傾き・箔の光沢、封書の形の「今夜の答え」を加えた。デスクトップ向けの拡大指定が記述順で効いていなかった不具合を直した。

## 次に優先するビジュアル制作

- 残りの数札40枚（エース〜10）を、優先度の高いもの（エース、よく知られた構図の3・5・10など）から個別の絵へ段階的に差し替える。2×2の4枚組で生成し、`src/data/tarotDeck.ts` の `minorWithOwnArt` と `src/data/cardImagery.ts` に加える。
- 小アルカナの数字・人物名は画像へ焼き込まず、書体・余白・色の調整をコード側で一括管理する。
- 個別絵を増やす場合もカードIDとファイル名の対応を崩さず、同じ構図・縁取り・色域を維持する。

## 次の体験改善

- 聞き返しの答えに合わせて、補足のカードを一枚引く（クラリファイア）。
- 語りの読み上げ（2026-09-27 時点で保留）。人物像を声で演じさせるなら、言葉で演技を指示できる Gemini の音声合成が有力（APIキーはサーバー側に置く）。保留の理由は、語りの本文を外部へ送ることと、音声の生成・読み込みの待ち時間。Web Speech API は無料だが声が平板。

## 音

- BGMは控えめな占い部屋風にする。長時間聞いても邪魔にならない音量とループを前提にする。

## 占い師の語りの継続調整

- 回答が説明文っぽくなりすぎないよう、実際の出力例を見ながらプロンプトを調整する。一方で、ほのめかしだけで終わらず「結局どういうことか」が伝わる明快さも保つ（比喩のあとに平らな言い直しを置く）。カウンセリングやコーチングの口調にはしない。
- 断定しすぎず、「気配があります」「カードはこう告げています」のように余韻を残す。
- 抽象的すぎる回答になった場合は、最後に今日できる小さな行動へ落とす指示を強める。
- 怖がらせない。悪いカードでも、注意点、距離の取り方、見直す場所として読む。
- 必要な安全配慮は、占い師の自然な言葉として柔らかく織り込む。
